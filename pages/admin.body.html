Вход для администраторов

Здесь меняются цены и фото каталога. Правки сохраняются в репозиторий сайта и через 1–2 минуты появляются у всех посетителей.

Защита входа — токен GitHub. Без токена сохранить изменения на сайт нельзя. Токен остаётся только в этом браузере и в файлы сайта не попадает.
Как создать токен (по шагам)
  1. Откройте страницу создания fine-grained токена (нужно быть залогиненным на GitHub).
  2. Имя любое, срок действия — на ваше усмотрение.
  3. Resource owner — аккаунт, которому принадлежит репозиторий Unus777/tile-catalog-demo.
  4. Repository access: Only select repositories → выберите только tile-catalog-demo.
  5. Repository permissions → Contents: Read and write. Остальные права не нужны.
  6. Нажмите Generate token, скопируйте его и вставьте в поле выше. Никому не пересылайте токен и не вставляйте его в чаты.
