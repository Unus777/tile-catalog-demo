# Каталог плитки — белая этикетка

Локально: `python3 -m http.server 8777` в этой папке → http://localhost:8777/

Название, контакты и адрес сайта задаются в одном файле **config.js**.

## Как переименовать и указать адрес
1. Откройте `config.js`. Поле `NAME` — название в шапке, заголовках и подвале (сейчас «Каталог плитки»). При желании заполните `TAGLINE`, `LEGAL_NAME`, телефон, WhatsApp, почту и адрес — пустые поля на сайте не показываются.
2. Перед публикацией пропишите `BASE_URL` без слэша в конце, например `'https://username.github.io/catalog'`.
3. Пересоберите страницы и QR-коды:
   ```
   python3 build_pages.py
   python3 tools/build_qr.py
   ```
   Если `BASE_URL` ещё пуст, в QR записывается шаблон `https://example.org/catalog/tile.html?a=АРТИКУЛ`.

## Страницы
- index.html — главная и каталог. Ссылки `index.html?f=60×60#catalog` работают как раньше; дополнительно `?s=Глянец`, `?c=Белый`, `?q=`, `?new=1`, `?sort=`. В шапке есть переключатель светлой и тёмной темы (по умолчанию светлая, выбор хранится в браузере).
- tile.html?a=АРТИКУЛ — страница модели. На неё ведут QR-коды.
- print.html — QR-коды на печать (A4, 3 в ряд; фильтр формата и «с ценами» — только на экране).
- prices.html — редактор цен (только после входа). Правило «безнал = нал + X %», округление до 10 ₽ по умолчанию, ручной безнал, экспорт/импорт JSON. Кнопка «Сохранить на сайт» публикует пачку цен одним коммитом в `prices.json`. Модели без своей цены показываются с пометкой «пример».
- edit.html — редактор фото (только после входа): кисть размытия, заливка, пипетка, отмена/повтор. «Сохранить в браузере» пишет в IndexedDB; «Сохранить на сайт» публикует JPEG в `overrides/` и запись в `photo-overrides.json`. Оригиналы каталога не затираются.
- admin.html — вход для администраторов. В подвале сайта есть мелкая ссылка «Вход для админов».

## Администраторы
Защита входа — **токен GitHub**. Без токена сохранить изменения на сайт нельзя. Токен хранится только в localStorage этого браузера: его нельзя коммитить и нельзя никому пересылать.

Как создать токен и войти:
1. Откройте [создание fine-grained токена](https://github.com/settings/personal-access-tokens/new) (нужно быть залогиненным на GitHub).
2. Имя любое, срок действия — на ваше усмотрение.
3. Resource owner — аккаунт, которому принадлежит репозиторий `Unus777/tile-catalog-demo`.
4. Repository access: **Only select repositories** → выберите только `tile-catalog-demo`.
5. Repository permissions → **Contents: Read and write**. Остальные права не нужны.
6. Generate token, скопируйте его и вставьте на странице `admin.html`.
7. После входа на карточках и странице модели появляются кнопки «Изменить цену» и «Изменить фото». «Сохранить на сайт» делает один коммит; GitHub Pages обновляет витрину за 1–2 минуты.

Публичные страницы читают `prices.json` (по артикулу `{cash, noncash}`) и `photo-overrides.json` с cache-bust — все посетители видят актуальные цены и правки фото.

## Данные
- data.js — собирается `python3 build_data.py` (нужна переменная окружения `CATALOG_SRC` с исходным data.json) + manifest.json.
  Поле `price: {cash, noncash, unit}` подхватывается, если есть в data.json; иначе цена из `prices.json`; иначе «пример».
- prices.json — опубликованные цены, которые видят все посетители.
- photo-overrides.json и overrides/ — опубликованные правки фото.
- img2/ — чистые фото (WebP+JPEG, srcset).
- img/, qr/ — галерея производителя и QR-коды моделей.

## Сборка и проверка
- `python3 build_pages.py` — собирает index/tile/prices/edit/admin.html из pages/.
- `node check.mjs` — headless Chromium 1440 и 390: скриншоты, ошибки, CLS, QR-ссылки.
- `node smoke.mjs index.html tile.html?a=VHP612038 prices.html edit.html admin.html` — быстрая проверка.
- `node test-admin.mjs` — вход, публикация цен (GitHub API мокается, в репозиторий ничего не пишется).
- room.bundle.js — 3D-примерочная (three.js, исходник src/).

Сайт статичный и может работать офлайн с GitHub Pages (файл `.nojekyll` уже лежит в корне).
